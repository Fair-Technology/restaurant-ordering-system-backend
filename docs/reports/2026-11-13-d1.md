## The command

Prerequisites: `az login`, subscription set, Owner (or Contributor + User Access Administrator — the template creates role assignments).

```sh
az account set --subscription <SUBSCRIPTION_ID>
az group create -n rg-restaurant-ordering-system-prod -l germanywestcentral \
  --tags product=restaurant-ordering env=prod

# Preview first — changes nothing:
az deployment group what-if -g rg-restaurant-ordering-system-prod \
  -f infra/main.bicep -p infra/main.prod.bicepparam

# Deploy:
az deployment group create -g rg-restaurant-ordering-system-prod \
  -f infra/main.bicep -p infra/main.prod.bicepparam
```

- Do not redeploy over a configured environment without re-applying settings: **this template replaces the Function App's whole app settings list** (README warning). Order for prod: deploy once, then set secrets, and do not re-run.
